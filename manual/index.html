CxM Image Viewer 操作マニュアル

Version 1.11 対応 / 2026-11-25  English version

CxM Image Viewerは、USBマイクロスコープ(H1612などUVCカメラ)と顕微鏡カメラの画像を、 ブラウザ上で表示・撮影・解析するための単一HTMLアプリです。インストール不要で、 同梱の start_viewer.bat をダブルクリックするだけで起動します。

1. 起動方法

A. ローカルサーバー(推奨・全機能)

  1. 配布ZIPを解凍します(index.html・start_viewer.bat・serve.ps1・README.txtが同じフォルダにある状態)。
  2. start_viewer.bat をダブルクリック → 既定ブラウザで http://127.0.0.1:8642/ が開きます。
  3. サーバーウィンドウを開いている間、アプリが利用できます。閉じると停止します。Python不要(Windows標準のPowerShellのみで使用)。

B. GitHub Pages(インストール不要)

ブラウザからプロジェクトページ(https://angewandtechemie.github.io/cxm-image-viewer/)へアクセスするだけで使えます。 HTTPSのページではカメラ機能(リアルタイム表示・動画・タイムラプス)もそのまま動作します。 解析結果の保存(PNG・テキスト・CSV)もブラウザのダウンロードとして行えます。

C. ファイル直接開き(制限あり)

index.html をダブルクリックでも開けますが、ブラウザの仕様でカメラが使えません(file://ではカメラAPI不可)。 保存した画像の解析のみ可能です。

対応ブラウザ: Chrome / Edge / Vivaldi などChromium系、およびFirefox(画像演算はWebGL対応ブラウザで動作)。

4. カメラ操作

  • リアルタイム解析: カメラ映像を表示し、設定した解析をリアルタイム(約10fps)で重ね描きします。
  • カメラ選択: 接続中のUVCカメラ(H1612、Webカメラ等)から選択します。
  • 解像度選択: 選択中のカメラが実際にサポートする解像度を一覧表示します(接続時に自動照会・カメラ単位で記憶)。 一覧が古い場合は「☐ 対応解像度を再照会」で更新できます。H1612では4K(3840×2160)が最上位です。
  • ch(画像演算): RGB / R・G・B単色 / Human Eye(R+G) / Red Enhance / Green Enhance / ExG / Red Index / Green Index / Blue Index / Pseudo Gray。表示・撮影・解析に共通適用。
  • フォーカス: H1612はスライダーで電子フォーカス操作可(0〜255、+/-キーで±5)。
  • 回転・反転・倍率: 90°回転、左右反転、デジタルズーム(1〜8倍)。ズーム時は画面上でドラッグしてパン。
  • 補正: ガンマ(0.2〜5.0)、コントラスト(0.2〜3.0)、シャープ(0〜2.0)、ノイズ低減(中央値/ガウシアン)、 フレーム平均(静止画のSN比向上)。自動ホワイトバランス(グレイワールド)と「全自動補正」(WB+ガンマ+コントラスト+ノイズ低減+フレーム平均の一括自動設定)付き。 補正値はカメラ・画像・保存・解析に共通適用されます。
  • 撮影(S): 現在の映像をPNG保存(映像のみ)。
  • 画像解析: 画像ファイルを読み込み。ギャラリーに複数画像を保持でき、クリックで画像解析モードとして開きます。

5. 動画撮影

  1. 「🎬 動画」→ 開始遅延(即時/3秒/10秒)と録画時間(10秒/30秒/任意)を選択 → 「🎬 動画撮影(V)」。
  2. 録画中は画面上部にRECマーカー(赤ドット+経過時間)と進行バーが表示されます(ファイルには焼き込まれません)。
  3. 「解析を含めて録画」(既定ON)をONにすると、測定線・ROI・統計ブロック・プロット・スケールバー等の解析オーバーレイを そのままの解像度で動画へインポーズします。OFFにすると映像のみを録画します。
  4. 遅延カウントダウン中は再クリックで取消、録画中は再クリックで停止。ファイルは サンプル名-動画.webm。

6. インターバル撮影

画像間隔撮影

「⏱ インターバル」→ 間隔(秒)と枚数(0=無制限)→「画像間隔撮影を開始」。 スケール・日時を焼き込んだ静止画を サンプル名-001.png 連番で自動保存します。 実行中は画面上部に進行マーカー(橙ドット+撮影枚数)と進行バーが表示されます。 ブラウザの「複数ファイルの自動ダウンロードを許可」が必要です。

タイムラプス撮影

総録画時間(分)と完成動画の長さ(秒)を設定して開始。指定間隔で撮影し、30fpsで短縮再生する1本のWebMに合成します (サンプル名-タイムラプス.webm)。実行中はTLマーカー(橙ドット+n/total)と進行バーが表示されます。

7. 解析機能

各モードはボタンまたはキーで切入。較正はモード共通で、一度較正すると全測定でmm表記になります。

モードキー操作出力
較正(基準長)C画像上の既知長さ(例: スケールバー)の両端を2点クリック → 実長(mm)を入力mm/px値。画像ごとに保持(同一解像度では自動適用)。較正線表示可
2点間距離M2点クリック(ドラッグで端点微調整)mm長・px・角度。複数本同時表示
角度N辺上点A→頂点B→辺上点Cの順に3点クリック頂点の内角(°)。較正不要
形状測定G円=円周上3点 / 矩形・正方形=対角2点 / 領域=四頂点4点半径・直径・面積・辺長・対角。頂点のドラッグ編集可
点分析P基準点→測定点(複数可)相対XY座標・ベクトル長・角度。CSV出力
線分析L断面線2点ドラッグ輝度プロット(300サンプル)。エッジ閾値で縁の位置を自動数値表示
面分析AROI多角形(左クリック=頂点、右クリック=確定)→「色指定」→目標色クリックROI面積・目標色画素数・占有率(%)。許容差調整可
粒子解析KROI+閾値(明/暗、Otsu自動)または色相区分(HSV)。最小面積・背景補正・接触分離(分水嶺)・円形度フィルタ粒子数・粒子径(等価円)統計(平均/中央値/四分位/範囲)・面積統計・円形度・縦横比。サイズ分布ヒストグラム(対数ビン、ImageJ風)。CSV出力(1粒子1行+ディスクリプタ)
解析結果は画面下部のテキストエリアに蓄積されます。ファイルへの出力は「💾 解析結果の保存(Shift+S)」 (描画込みPNG+結果テキスト)と各パネルのCSV/HTMLレポートのみです。解析の確定ごとにTXTが自動保存されることはありません。

保存・出力

  • 💾 解析結果の保存(Shift+S): 解析描画を焼き込んだPNG(-A.png)と結果テキスト(-A.txt)。
  • 📄 レポート出力: スナップショット+解析結果+解析条件(JSON)を1枚のHTMLレポート(-レポート.html)として保存。
  • ⚙ 解析条件: 較正値・全解析条件・表示設定をJSONへエクスポート/インポート。リセット。

8. 画像比較

「🔀 比較」→「現在フレームを固定(開始)」で現フレームをReference(左)に固定し、右にライブ(Sample)を表示。 ブロック単位の差分率をヒートマップと差分ブロック数で表示します。Referenceは画像ファイルからの読み込みも可能。

10. トラブルシューティング

症状対処
「カメラ開始失敗」他のアプリ(純正ビューア等)がカメラ使用中 → 閉じる。ブラウザのカメラ許可を確認
カメラが映らない(file://)ファイル直接開きではカメラ不可。start_viewer.batまたはGitHub Pagesを使用
解像度一覧に目的値がないそのカメラが実際にサポートする解像度のみ表示されます。「☐ 対応解像度を再照会」を試す
画像が黄色/緑っぽい「補正 ▾」→「自動ホワイトバランス」または「全自動補正」
粒子が細かく分断閾値を下げる/背景補正を上げる/最小面積を上げる
接触した粒子が1塊になる「接触分離」にチェック(分水嶺分割)
長さがpxのままCで較正(画像内の基準長さでmm化)
画像解析モードでスケールバーが消えた仕様です(自動OFF)。カメラモード復帰で自動復元。必要なら「表示ON/OFF」→スケールでON
ダウンロードされないブラウザの複数ファイル自動ダウンロードを許可
