CxM Image Viewer User Manual

For Version 1.11 / 2026-11-25  日本語版

CxM Image Viewer is a single-HTML browser app for displaying, capturing and analyzing images from USB microscopes (H1612 and other UVC cameras). No installation is needed: just double-click the bundled start_viewer.bat to launch it.

1. Launching

A. Local server (recommended, full features)

  1. Unzip the distribution ZIP (keep index.html, start_viewer.bat, serve.ps1 and README.txt in the same folder).
  2. Double-click start_viewer.bat → your default browser opens http://127.0.0.1:8642/.
  3. The app is available while the server window stays open; closing it stops the server. No Python required (Windows built-in PowerShell only).

B. GitHub Pages (nothing to install)

Simply open the project page (https://angewandtechemie.github.io/cxm-image-viewer/) in a browser. On this HTTPS page the camera features (live view, video, time-lapse) work as-is. Analysis outputs (PNG, text, CSV) are saved through normal browser downloads.

C. Opening the file directly (limited)

Double-clicking index.html also works, but the browser disables the camera API on file:// pages. Only analysis of saved images is available that way.

Supported browsers: Chromium-based (Chrome / Edge / Vivaldi) and Firefox (image math requires WebGL).

4. Camera controls

  • Real-time analysis: shows the camera image and overlays the configured analysis in real time (~10fps).
  • Camera ▾: pick from connected UVC cameras (H1612, webcams, etc.).
  • Resolution ▾: lists the resolutions the selected camera actually supports (probed at connect time, remembered per camera). Use "☐ Re-query supported resolutions" to refresh the list. For the H1612, 4K (3840×2160) is the top entry.
  • ch (image math): RGB / R, G, B single channel / Human Eye (R+G) / Red Enhance / Green Enhance / ExG / Red Index / Green Index / Blue Index / Pseudo Gray. Applied to display, capture and analysis alike.
  • Focus: the H1612 supports electronic focus via slider (0–255, +/- keys step by 5).
  • Rotate / zoom ▾: 90° rotation, mirror, digital zoom (1–8×). While zoomed, drag on the image to pan.
  • Corrections ▾: gamma (0.2–5.0), contrast (0.2–3.0), sharpen (0–2.0), noise reduction (median / Gaussian), frame averaging (SNR gain for static scenes). Includes auto white balance (gray world) and "Auto-correct all" (one-click WB + gamma + contrast + noise reduction + frame averaging). Corrections apply to camera, image, capture and analysis alike.
  • Capture (S): save the current video frame as PNG (video only).
  • Image analysis: load an image file. The gallery keeps multiple images; click one to open it in analysis mode.

5. Video recording

  1. "🎬 Video" → choose start delay (immediate / 3 s / 10 s) and record length (10 s / 30 s / Manual) → "🎬 Record video (V)".
  2. While recording, a REC marker (red dot + elapsed time) and a progress bar are shown at the top of the screen (not baked into the file).
  3. With "Bake analysis into recording" (default ON), measurement lines, ROIs, the stats block, plots, the scale bar etc. are composited into the video at full resolution. With OFF, only the video is recorded.
  4. Click again to cancel during the countdown, or to stop while recording. File: samplename-video.webm.

6. Interval capture

Image interval capture

"⏱ Interval" → interval (s) and frame count (0=unlimited) → "Start image interval capture". Stills with scale and timestamp baked in are auto-saved as samplename-001.png numbered files. While running, a progress marker (orange dot + frame count) and progress bar are shown. Allow "automatic multiple file downloads" in your browser.

Time-lapse capture

Set the total recording time (min) and the output video length (s), then start. Frames are captured at the derived interval and composed into one WebM played back faster at fixed 30fps (samplename-timelapse.webm). While running, a TL marker (orange dot + n/total) and progress bar are shown.

7. Analysis functions

Modes are toggled by button or key. Calibration is shared across modes: once calibrated, all measurements show mm.

ModeKeyOperationOutput
Calibration (reference length)CClick the two ends of a known length in the image (e.g. a scale bar) → enter its true length (mm)mm/px value, kept per image (auto-applied at the same resolution). Calibration line displayable

AngleNClick point A on one side → vertex B → point C on the other sideInterior angle at the vertex (°). No calibration needed

Point analysisPReference point → measurement points (multiple)Relative XY, vector length, angle. CSV output
Line profileLDrag a 2-point section lineBrightness plot (300 samples). Edge threshold auto-labels edge positions
Area analysisAROI polygon (left-click=vertex, right-click=confirm) → "Pick color" → click the target colorROI area, target-color pixel count, coverage (%). Tolerance adjustable
Particle analysisKROI + threshold (bright/dark, Otsu auto) or hue classification (HSV). Min area, background correction, watershed split, circularity filterCount, equivalent-circle diameter stats (mean/median/IQR/range), area stats, circularity, aspect ratio. Size histogram (log bins, ImageJ-style). CSV (one row per particle + descriptor)
Analysis results accumulate in the text area at the bottom. File output happens only via "💾 Save analysis (Shift+S)" (PNG with drawing + results text) and the per-panel CSV / HTML report. A TXT file is never auto-saved when an analysis is confirmed.

Save & export

  • 💾 Save analysis (Shift+S): PNG with the analysis drawing baked in (-A.png) + results text (-A.txt).
  • 📄 Export report: snapshot + analysis results + analysis conditions (JSON) as a single HTML report (-report.html).
  • ⚙ Conditions: export/import calibration and all analysis/display settings as JSON. Reset.

8. Image comparison

"🔀 Compare" → "Freeze current frame (start)" pins the current frame as Reference (left) and shows live Sample (right). Per-block difference is shown as a heatmap plus a diff-block count. The Reference can also be loaded from an image file.
